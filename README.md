# Introducción a R

Este repositorio contiene ejercicios básicos realizados en R para practicar conceptos fundamentales del lenguaje.

## Contenido del código

El código incluye:

- Operaciones matemáticas básicas.
- Uso de variables.
- Creación y manipulación de vectores.
- Uso de índices y filtros.
- Creación y modificación de Data Frames.
- Lectura de archivos CSV.
- Análisis exploratorio de datos.
- Gráficas estadísticas.
- Modelo de regresión lineal.
- Evaluación de residuos y prueba de normalidad.
- Visualización de la recta de regresión con ggplot2.

## Librerías utilizadas

- dplyr
- ggpubr
- ggplot2

## Objetivo

Practicar estructuras básicas de R y realizar un análisis simple de salarios en función de la experiencia laboral.
